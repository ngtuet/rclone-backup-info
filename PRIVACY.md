# Privacy policy

This OAuth client ("rclone-backup") is a personal tool. Only its owner uses it.

- **What it accesses:** only the files and folders in Google Drive that the tool itself created (Google scope `drive.file`). It cannot see other files in the Drive.
- **What it does:** it uploads backup files from the owner's computer to the owner's own Google Drive and reads them back for a restore.
- **What it collects:** nothing. No data is sent to anyone other than Google Drive, and nothing is shared, sold or analysed.
- **Other users:** there are none. If you are not the owner, this client is not meant for you.

Questions: open an issue in this repository.
